NESTED ZELLIJ local ⊃ ssh ⊃ zellij

Open zellij locally, SSH into another box, run a zellij there → the outer (local) session grabs Ctrlg, so the inner (remote) one never sees it. Fix: start the inner one with zin, which uses Ctrlo as its control key.
zinStart the inner/remote zellij (control = Ctrlo)
zind…same, with the loki-dev yazi-sidebar layout
Ctrl gControls the outer (local) zellij — as always
Ctrl oPasses through the outer → controls the inner (remote) zellij
Ctrl bPasses through both → controls tmux at any depth
Driving the inner session
Ctrlo → p/t/r…Take control of inner, then use mode keys normally
EscInner back to locked (passes straight through)
Caveat: the outer eats the Alt* shortcuts that zellij binds (incl. Alty) in locked mode, so to drive the inner session use mode-based keys (Ctrlo then p…) rather than the Alt combos. Three layers stay distinct: outer Ctrlg · inner Ctrlo · tmux Ctrlb.
Exception — yazi. Altk is deliberately not bound in zellij, so it falls through both layers to the shell that has focus — press it on the inner/remote pane and yazi opens on the remote box (the real "SSH passthrough"). On Windows, zellij is native (0.44+), so a local Windows zellij can be the outer layer (Ctrlg) — start it with Lz/zd, then SSH out and zin for the inner (Ctrlo). Or skip it: PowerShell + SSH forward the keys, so the first zellij you start after SSHing in is the outer. WezTerm's leader Ctrla clashes with nothing at any depth.

PORTING ~/.loki-term

Everything lives in ~/.loki-term. To replicate on any machine:
1scp -r ~/.loki-term you@box:~/  (or git clone)
2~/.loki-term/install.sh — installs tools + links configs
3source ~/.bashrc (or open a new shell)
install.sh flags
--no-toolsOnly symlink configs (tools already present)
--tools-onlyOnly install packages, don't touch dotfiles
Backs up anything it replaces to <file>.pre-loki.<timestamp>. Needs a Nerd Font for icons (JetBrainsMono is bundled by the installer).
